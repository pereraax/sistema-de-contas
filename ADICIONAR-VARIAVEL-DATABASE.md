# ✅ Adicionar Variável DATABASE_ENABLED

## 🎯 **SOLUÇÃO RÁPIDA:**

Adicione esta variável no Render para corrigir o erro:

### **No Render Dashboard:**

1. **Vá em:** Seu serviço `evolution-api`
2. **Clique em:** "Environment" (menu lateral)
3. **Clique em:** "Add Environment Variable"
4. **Adicione:**
   ```
   Key: DATABASE_ENABLED
   Value: false
   ```
5. **Salve** (Render vai reiniciar automaticamente)
