DEPOIS DE CONECTAR, EXECUTE:
============================

cd public_html
npm install
nano .env.production
# (Cole variáveis e salve: Ctrl+X, Y, Enter)
npm run build
npm install -g pm2
pm2 start npm --name "sistema-contas" -- start
pm2 save
pm2 status

===========
- Clique em "Alterar" na tela SSH para ver/definir senha
- A senha não aparece enquanto você digita (é normal!)
- Se não tiver Node.js 20, configure no painel Hostinger
