PleniPay CRM WhatsApp

Configure API, mensagens e funis de envio

API do site (URL e token)

Usada para enviar mensagens pelo servidor (Evolution API no backend).

Mesmo valor da variável EXTENSION_CRM_API_KEY no servidor.

Configuração salva.

Mensagens

Cada mensagem aparece como um botão na barra do WhatsApp. Você pode adicionar botões (ex.: CADASTRAR com link) na mensagem.

    Nova mensagem

    Se preencher URL, o botão abre o link; senão é botão de resposta.

    Funis

    Um funil é uma sequência de mensagens na ordem que você definir. Na extensão, um único clique envia todas as mensagens do funil em sequência para o contato atual.

      Novo funil

      Adicione as mensagens na ordem em que devem ser enviadas. O primeiro da lista é enviado primeiro.
